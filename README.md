# NumPy によるニューラルネットワークの実装と果物画像の分類

> **実施時期:** 2024年10月〜2025年1月（学部3年 Aセメスター、大学の講義の課題として実施）
> **Git 管理:** 2026年10月25日から（就職活動での公開にあたり、README.md と .gitignore を追加しました。コードは当時のまま変更していません）

## 概要

深層学習のライブラリを使わず、**NumPy だけでニューラルネットワークを一から実装**し、果物・野菜の画像をカテゴリーごとに分類する実験を行いました。

- **データ:** Fruits-360 の画像（100×100）から 10 カテゴリーを選んで使用
- **入力:** 画像を 10×10 に縮小し、RGB の値を並べた 300 次元のベクトル（0〜1 に正規化）
- **ネットワーク:** 全結合層のみ。各層は 300 次元で、最終層だけカテゴリー数の次元
  - 活性化関数は ReLU、最終層のみ softmax
  - 層の数は引数で変えられるようにし、隠れ層を増やした場合（DNN）も試せるようにした
- **学習:** 訓練データからランダムに 1 枚選んで誤差逆伝播で重みを更新する処理を、出力誤差のノルムが 0.03 以下になるまで繰り返す（学習率 0.01）

考察などの詳細はレポートにまとめています。

### 畳み込み層について

CNN にするため、畳み込み層・プーリング層とその逆伝播も実装しました（[net.py](net.py) の `Convolution`、`Pooling`、`Back_Convolution`、`Back_Pooling`）。しかし、カーネル（共有される重み）の更新方法を当時は正しく理解できず、学習がうまくいきませんでした。そのため実験では `useConvolution = False` とし、全結合層のみを使っています。

## 実験と結果

各条件で 3 回ずつ実行しました。

| 実験 | 内容 |
|---|---|
| (1) | 層の数（3〜5 層）とカテゴリー数（2, 5, 8, 10）を変えたときの正解率 |
| (2) | 学習の終了条件を「誤差が n 回しきい値以下になるまで」に変えたときの正解率 |
| (3) | 訓練データにノイズ（各画素を確率 d% でランダムな値に置換）を加えたときの正解率 |
| (4) | 訓練データにノイズ 25% を加えたときの、カテゴリー数ごとの正解率 |
| (5) | テストデータにノイズを加えたときの正解率 |

実験 (1) の 3 層（隠れ層 1 層）の平均正解率:

| カテゴリー数 | 2 | 5 | 8 | 10 |
|---|---|---|---|---|
| 正解率 | 100% | 69.98% | 58.80% | 62.40% |

主な結果:

- 層を増やしても正解率は上がらず、3 層が最もよかった
- 訓練データに少しノイズを加えると正解率が上がる場合があった（3 層・5 カテゴリーでノイズ 5% のとき平均 79.30%）が、ノイズを増やしすぎると下がった
- 層が多いほど、ノイズによる正解率の低下が大きかった

## 使用技術

- Python 3.8
- NumPy（ネットワークの実装）
- OpenCV（画像の読み込み・リサイズ）

## ディレクトリ構成

```
numpy_NN_B3_A_semester/
├── net.py        # ニューラルネットワーク本体（順伝播・誤差逆伝播・活性化関数・畳み込み層など）
├── read_data.py  # 訓練データ・テストデータの読み込み
└── run .py       # 学習とテストを行い正解率を表示（ファイル名の空白は当時のまま）
```

## 実行方法

```bash
pip install numpy opencv-python
```

画像データはリポジトリに含めていません。[Fruits-360](https://www.kaggle.com/datasets/moltean/fruits) から画像を取得し、次の構成で配置してください（フォルダ名はカテゴリー名）。

```
data/
├── traindata/
│   ├── apple_green/
│   ├── apple_red/
│   └── ...（avocado, banana, blueberry, cabbage, carrot, cauliflower, cherry, corn）
└── testdata/
    └── images/
        ├── apple_green/
        └── ...
```

リポジトリのルートで実行します。

```bash
python "run .py"
```

`run .py` のカテゴリーやノイズの設定は、最後に行った実験のもの（10 カテゴリー、訓練データにノイズ 25%）になっています。
